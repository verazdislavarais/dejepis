# dejepis
Materiály pro výuku dějepisu.

## Struktura webu

- `docs/index.html` — úvodní stránka a rozcestník.
- `docs/assets/css/site.css` — společné styly.
- `docs/materialy/tricetileta-valka/` — výukové soubory k třicetileté válce.

Pro další téma založte vlastní složku v `docs/materialy/` a přidejte odkaz do rozcestníku. Samostatná stránka tématu může být v `docs/temata/<tema>/index.html`.

GitHub Pages publikuje složku `/docs` z větve `main`. Starší přímé odkazy na první dva materiály zůstávají dostupné.
